## Biomarker Discovery: From Theory to Real-World Examples

The **Biomarker Discovery** course, hosted via the SciLifeLab Training Portal and delivered by National Bioinformatics Infrastructure Sweden (NBIS), provides an intensive overview of experimental design, multi-omics integration, and statistical learning methodology in biomarker research. Designed for academic and industry researchers, this national course bridges theoretical concepts and practical computational implementations in R.

## 5. Curriculum & Core Topics

The course combines lectures on biological study design with practical data analysis exercises. Participants explore how diagnostic, prognostic, and wellness biomarkers move from initial discovery in high-throughput data to clinical application.

### Pipeline Framework Overview

| Phase | Core Focus | Methods & Modalities | Key Analytical Outputs |
| :--- | :--- | :--- | :--- |
| **1. Clinical Context & Design** | Biomarker classification & trial design | Diagnostic, prognostic, and wellness biomarkers | Context of Use (COU) specification |
| **2. Omics Data Integration** | High-throughput feature profiling | Proteomics, microbiomics, multi-omics fusion | Batch-corrected, integrated tabular data |
| **3. Machine Learning & Validation** | Supervised feature selection & evaluation | Lasso logistic regression, Random Forest | Performance metrics (ROC/AUC, Sensitivity, Specificity) |

### Main Modules Covered

1. **Biomarker Study Design & Context of Use**:
   - Aligning biomarker search strategies with specific clinical contexts of use (COUs).
   - Differentiating diagnostic, prognostic, and wellness/monitoring biomarkers.
   - Case studies in major disease areas, including oncology and cardiovascular disorders.

2. **Omics Data Platforms**:
   - High-throughput biomarker extraction from proteomic and microbiomic datasets.
   - Principles of data normalization and batch correction in molecular profiling.

3. **Multi-Omics Data Integration**:
   - Frameworks for merging disparate biological data layers (e.g., proteomics + microbiome).
   - Addressing dimensional heterogeneity and missing values across omics tables.

4. **Machine Learning & Statistical Identification**:
   - Feature selection algorithms optimized for high-dimensional biological data ($p \gg n$).
   - Implementation of Penalized Logistic Regression (Lasso) and Random Forest classifiers.

5. **Validation & Performance Evaluation**:
   - Statistical metrics: Sensitivity, Specificity, Receiver Operating Characteristic (ROC), and Area Under the Curve (AUC).
   - Strategies for internal cross-validation and independent external cohort validation.

6. **AI-Assisted R Scripting**:
   - Leveraging GitHub Copilot within RStudio to accelerate script development, debugging, and data processing workflows.

## 6. Intended Learning Outcomes

Upon successful completion of the course, participants are expected to demonstrate competency in six core areas:

1. **Study Design Assessment**: Identify key challenges and design considerations for context-specific biomarker discovery trials.
2. **Omics Data Processing**: Execute fundamental bioinformatic workflows on processed proteomic and microbiomic data matrices.
3. **Data Fusion**: Construct data pipelines that integrate multi-omics datasets into unified analytical frames.
4. **Supervised Classification**: Build and evaluate Lasso logistic regression and Random Forest models on tabular omics data in R.
5. **Diagnostic Accuracy Evaluation**: Calculate and interpret biomarker performance indicators, including sensitivity, specificity, and validation metrics.
6. **AI Code Generation**: Utilize GitHub Copilot effectively to write and optimize analytical R scripts.

## 7. Prerequisites and Technical Setup

To participate fully in hands-on computer labs, attendees must meet specific software and knowledge requirements.

### Mandatory Requirements

- **Hardware**: Personal laptop capable of running computational workflows in R.
- **Software**: Recent installation of R and RStudio.
- **Programming Competency**: Working knowledge of R scripting (data manipulation, plotting, basic function calls) or prior completion of an equivalent NBIS introductory R course.

### Recommended Preparation

- Fundamental understanding of introductory biostatistics (hypothesis testing, regression).
- Prior exposure to molecular biological studies or biomarker research pipelines.
- An active GitHub account with GitHub Copilot Pro enabled (free tier available for academic students and teachers).
